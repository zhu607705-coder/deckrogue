# 战锤机制实现对照文档

## 1. 亚空间与腐化体系

### 1.1 现有机制 (已实现)

#### ✅ 1.1.1 腐化度系统
- **状态**: `player.corruption` (0-100)
- **影响**: 
  - `warpTide` 状态根据腐化度自动计算
  - 高腐化触发 `isWarpBoiling` 状态
  - Warp Tide 等级影响视觉效果

#### ✅ 1.1.2 信仰度系统
- **状态**: `player.devotion` (0-100)
- **影响**:
  - 与腐化度形成二元对立
  - Axis Dial UI 显示信仰/腐化轴

#### ✅ 1.1.3 已有腐化相关卡牌

| 卡牌 | 类型 | 效果 |
|------|------|------|
| `corrupted_bargain` | 技能卡 | 获得 2 能量，+8 腐化，随机敌人 +2 强化 |
| `tainted_strike` | 攻击卡 | 1费 6伤害，+3 腐化，有3+腐化时+5伤害 |
| `warp_rush` | 技能卡 | 0费，+5 腐化，抽2牌，弃1牌 |
| `inner_darkness` | 能力卡 | 所有攻击卡+2伤害但+2腐化 |
| `corrupted_defense` | 技能卡 | 获得8格挡，+4腐化，有5+腐化时+4格挡 |

#### ✅ 1.1.4 已有腐化相关遗物

| 遗物 | 效果 |
|------|------|
| `heretics_metronome` | 每回合第4张卡0费，但受3点伤害 |
| `corrupted_relic` | 每次受伤+1腐化，有20+腐化时+1力量 |
| `corrupted_tome` | 每次抽牌+1腐化，有腐化时抽牌+1 |
| `mark_of_chaos` | 回合开始时+2腐化，有30+腐化时+1能量 |
