# 战斗结算顺序

## 当前版本唯一顺序
1. 出牌声明
2. 扣费
3. 目标确认
4. 主效果执行
5. 附加触发
6. 死亡判定
7. 回合后结算

## 说明
- 同一语义的效果应复用统一 action 定义。
- 死亡判定必须发生在主效果和附加触发之后。
- 回合结束、回合开始、持续状态结算必须在固定窗口内执行。
- 相同 seed 下，触发顺序必须稳定。

## 当前版本要求
- 关键非法状态必须尽早记录：
  - 费用小于 `0`
  - 抽牌数量异常
  - 已销毁对象继续触发
  - 战斗已结束仍进入结算
  - 读档后实体 ID 不匹配
- 新增机制若无法映射到这套顺序，视为下版本 backlog，不进入当前版本。
