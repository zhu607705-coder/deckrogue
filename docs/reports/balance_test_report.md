## 1. 测试概览

### 测试配置
- **每职业测试局数**: 20 局
- **最大层数**: 5 层
- **测试策略**: 平衡型（优先战斗房间）
- **AI 决策**: 基于卡牌评分的贪婪策略

### 关键指标
- **3F 胜率**: 前 3 层存活率（核心平衡指标）
- **5F 胜率**: 完整通关率
- **平均回合**: 每场战斗的平均回合数
- **综合得分**: 综合评估分数

### 2.2 平衡性分析

#### 强势职业
- **Tactician (90%)**: 策略系统过于强大，需要微调
- **Puppeteer (85%)**: 构造体系统表现良好

#### 弱势职业
- **Alchemist (65%)**: 元素系统启动慢，战斗回合过长
- **Informant (65%)**: 情报系统收益不稳定

#### 正常职业
- **Brute (80%)**: 力量系统平衡良好
- **Chronomancer (75%)**: 时间系统表现正常

## 3. 发现的问题

### 3.1 缺失动作类型
测试中发现以下动作类型未实现：

| 动作类型 | 状态 | 修复 |
|----------|------|------|
| PrecisionThrowDamage | ❌ 缺失 | ✅ 已修复 |
| ForceEnemyAttack | ❌ 缺失 | ✅ 已修复 |
| SolventDamage | ❌ 缺失 | ✅ 已修复 |
| PurgeEnemyBuffs | ❌ 缺失 | ✅ 已修复 |

### 3.2 平衡性问题

#### Alchemist 问题
1. **战斗回合过长**: 平均 6.6 回合（其他职业 3-4 回合）
2. **元素系统启动慢**: 需要多回合积累元素
3. **伤害输出不足**: 依赖元素反应，前期伤害低

#### Informant 问题
1. **情报收益不稳定**: 需要特定卡牌配合
2. **防御能力弱**: 缺乏有效防御手段

#### Tactician 问题
1. **胜率过高**: 90% 胜率超出目标范围
2. **策略卡过强**: 需要微调

## 4. 已实施的修复

### 4.1 动作类型修复

```typescript
// 新增动作类型
PrecisionThrowDamageAction  // 精准投掷伤害
ForceEnemyAttackAction      // 强制敌人攻击
SolventDamageAction         // 溶剂伤害
PurgeEnemyBuffsAction       // 清除敌人增益
```

### 4.2 平衡性调整

#### Alchemist 调整
- 起始卡组：移除 chain_reaction，增加 fire_arrow 和 frost_armor
- element_spark：添加 3 点格挡
- fire_arrow：伤害 7 → 8
- 元素反应：Fire+Lightning 伤害 10 → 12

#### 效果对比

| 指标 | 调整前 | 调整后 | 改善 |
|------|--------|--------|------|
| 3F 胜率 | 50% | 65% | +15% |
| 平均回合 | 7.4 | 6.6 | -0.8 |

## 6. 测试脚本使用说明

### 运行测试
```bash
# 全职业测试
npx tsx scripts/balance_test.ts --runs=20 --floors=5

# 单职业测试
npx tsx scripts/balance_test.ts --class=alchemist --runs=20

# 快速测试
npx tsx scripts/balance_test.ts 10
```

### 参数说明
- `--runs=N`: 每职业测试局数（默认 20）
- `--floors=N`: 最大层数（默认 5）
- `--class=NAME`: 指定测试职业
